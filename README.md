# Presentation Script Reader App

A pronunciation scaffolding application designed to help users read and practice presentation scripts.

## Repository Contents

| File | Description |
|------|-------------|
| `Presentation Script Reader App.make` | Figma design file (`.make` format) containing the UI/UX mockups for the app |

## Project Overview

This app is part of the broader **Pronunciation Scaffolder** toolset developed at TNT Lab. It is intended to assist learners in reading presentation scripts aloud, providing scaffolded support for pronunciation practice.

## Related Projects

- `PronunciationScaffolder/` — Elm/JavaScript implementation of the pronunciation scaffolder
